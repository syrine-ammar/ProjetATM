# 💳 Secure ATM Simulator using JavaCard
![atm interface](https://github.com/user-attachments/assets/00a515e7-527a-453e-8777-be95944196aa)


This project is a secure ATM simulator developed as part of an end-of-semester mini project. It integrates a Java Swing-based graphical user interface with a secure JavaCard applet, simulating real-world ATM functionalities such as PIN verification, balance inquiry, transactions, and secure communication.

## 🔐 Objective

To simulate an ATM environment where security and data integrity are key by:
- Using a JavaCard for secure applet deployment.
- Enabling client-server communication via sockets.
- Providing a user-friendly Java Swing GUI.

## 🛠️ Tech Stack & Concepts

- **JavaCard**: Developed secure smart card applets for authentication and transaction logic.
- **Java Swing**: Built the client-side desktop interface.
- **NetBeans IDE**: Used for coding, debugging, and managing the project.
- **APDU (Application Protocol Data Unit)**: Facilitated communication between Java Swing and JavaCard.
- **Socket Programming**: Enabled TCP/IP communication between the client and server.

## 📌 Features

- 🔐 **PIN Verification**  
  Secure login with a retry limit to prevent brute-force attacks.

- 💰 **Add / Withdraw Money**  
  Users can perform deposits and withdrawals with proper balance checks.

- 📊 **Balance Inquiry**  
  Check the current account balance securely.

- 💼 **Transaction History**  
  View a record of recent transactions.

## 📚 Learning Outcomes

This project deepened understanding in:
- Embedded system development using JavaCard.
- Secure application design and communication protocols.
- Client-server architecture and smart card interaction.

## 🚀 Getting Started

> To run this project, you need:
- JavaCard Development Kit 2.2.2+
- NetBeans with JavaCard plugin
- A simulated or physical JavaCard environment
- Java 1.7+ installed
- Java Swing-compatible environment
